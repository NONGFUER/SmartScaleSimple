# SmartScale 项目配置与文件读写目录清单

> 整理自源码实际路径，便于部署 / 备份 / 排障时核对。
> 约定：`appDir` = 可执行文件所在目录（`QCoreApplication::applicationDirPath()`）；
> `HOME` = 运行用户家目录（`QDir::homePath()`）。

## 1. 应用目录内（appDir，通常为 `/opt/SmartScale` 或部署目录）

| 路径 | 类型 | 读写方 | 说明 |
|------|------|--------|------|
| `appDir/data/smartscale.db` | SQLite 数据库 | `DatabaseManager` (`main.cpp:183`) | 离线账号 / 称重记录主库，启用 WAL（`-wal`/`-shm` 副文件同目录） |
| `appDir/data/smartscale.log` | 日志 | `main.cpp:160` | 运行日志，超过 2MB 自动截断重建 |
| `appDir/data/ota/` | 目录 | `OtaService` | OTA 升级工作区（见下表） |

| 路径 | 类型 | 说明 |
|------|------|------|
| `data/ota/update.part` | 下载临时包 | 流式下载落盘，校验通过后改名 |

| `~/.config/SmartScale/last_login.conf` | INI | `AuthService` (`kLastLoginPath:728`) | 记住登录：userCode + 密码 **base64（等同明文，有泄露风险）** |

## 6. 部署 / 备份建议

**必备份（业务数据，丢失影响使用）：**
- `appDir/data/smartscale.db`（含离线账号与历史记录）
- `~/.config/SmartScale/`（登录记忆 + 用户设置）
- `~/.cache/smartscale/`（productId / 登录历史缓存）

**可选备份：** `appDir/data/smartscale.log`（排障）、`~/Pictures/*.jpg`（拍照成品）。

**部署注意：**
- OTA 脚本 `apply_update.sh` 不在源码目录，必须从 qrc 导出；设备端需保证 `data/ota/` 可写。
- TTS 模型目录与 sherpa-onnx .so 当前为开发机绝对路径，**发布到设备须改为设备实际路径**（建议改为相对 `appDir` 或环境变量注入）。
- DB 用 WAL，备份时应同时包含 `-wal`/`-shm`，或先正常关闭进程再备份。

## 7. 已知风险

- `last_login.conf` / `login_history.json` 中密码仅 base64 编码 = 明文，建议改不持久化或 AES 加密（见项目记忆 Auth 章节）。
- **MQTT 密码明文存储**：`~/.config/SmartScale/SmartScale.conf`（`[MqttShxgs]` `Password`）为明文；且 `MqttClientService::initAndConnect`（`MqttClientService.cpp:1324-1327`）用 `qInfo()` 把明文 SN/Password 打到 stdout/日志，若日志落盘（`data/smartscale.log`）会泄露，**建议改为掩码或删除调试打印**。
- **Wi-Fi 密码明文存储**：`~/.config/SmartScale/wifi_passwords.conf` 按 SSID 明文缓存 PSK，无加密。
- TTS 模型 / sherpa 路径硬编码，跨机部署需调整（见上）。
